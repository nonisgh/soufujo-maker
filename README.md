# 送付状メーカー

AIが書いた送付状の文章を貼るだけで、A4・1枚の送付状をきれいに印刷できるツールです。
ChatGPT・Gemini・Claude など、どのAIの文章でも、同じレイアウト・同じ字体（Noto Serif JP）になります。

**ひらく：** https://nonisgh.github.io/soufujo-maker/

## つかいかた
1. 送付状メーカーの「AI用ルールをコピー」を押してAIに貼り（または「ダウンロード」したファイルを添付し）、【入力】を書きかえて送る
2. AIの答えをまるごとコピーして、送付状メーカーの左の欄に貼る
3. はじめて使うときは「差出人」に自分の住所・氏名を入力する（このブラウザにだけ保存されます）
4. 右の送付状を確認して「印刷・PDFに保存」
   印刷設定：送信先「PDFに保存」／用紙 A4／倍率 100%／余白 なし／ヘッダーとフッター オフ

## できること
- 「AI用ルールをコピー／ダウンロード」で、AIに渡すルール（prompt.md の中身）をすぐ使える
- 日付が `today`（または空欄）なら今日の日付（令和）、`today:s` なら今日の日付（西暦）を入れる
- 本文に `{時候}` と書くと、日付の月に合った季節のあいさつ（例：11月なら「晩秋の候」）を入れる。月に合わないあいさつは赤い字で注意
- 宛名は「会社名・部署・名前」の複数行、「様」「御中」「さん」「各位」（関係者各位のようにすき間なし）に対応
- 連名（例：岡田　謙吾　様／岡田　絢子　様）。2人目から姓を省く書き方も選べる
- 「拝啓」で始めれば「敬具」、「前略」なら「草々」を自動で入れる。拝啓なしの短い送付状もOK
- 同封物の番号の形を選べる（1.／（1）／①／i.／I.／a.／・／なし）、点線、備考（※）
- 差出人の名前を左（住所の頭にそろえる）か右（住所の終わりにそろえる）に置ける
- 宛名の下線（あり／なし）と同封物の線（点線／実線／なし）を選べる
- 間かく（上の余白、日付→宛名、宛名→差出人、差出人→タイトル、タイトル→本文、本文→記）を mm で変更。0 で間をあけない
- モード（ゆったり／フォーマル／コンパクト）で、文字の大きさ・タイトルの字の間・間かくをまとめて切りかえ
- 長い同封物の名前は文節の切れ目で折り返す。「//」を入れるとそこで改行（本文・備考は「<br>」で改行）
- 文字の大きさを場所ごとに変更（日付・宛名・差出人・タイトル・本文・記・備考）
- 同封物が入りきらないときは、2枚目に「別紙　同封書類一覧」を自動で作る（いつも別紙／使わない も選べる）
- 同封物などが多くて長くなると、余白と本文の行間を自動でつめて（読みやすさを保つ範囲で）1枚に収める。それでも収まらないときは赤い字で警告

差出人・文字の大きさ・貼った文章は、使っているブラウザの中にだけ保存され、どこにも送信されません。
